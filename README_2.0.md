# Дальний рейс 2.0

Симулятор дальнобойщика для PSP (homebrew).

## Что есть
- State machine: меню → гараж → компьютер → езда → телефон → сдача груза → радио
- Гараж с орбитальной камерой (стик)
- Прицепление прицепа и сдача с бонусами (0 / +1000 / +2500)
- Автоопределение заезда передом/задом
- 4 города: ПРИВОЛЬСК, СЕВЕРОДОНСК, ГРУЗОВОЙ, МОРСК
- HUD 2.0, мини-карта с городами
- Радио (4 станции-заглушки)
- Заставка menu.bmp
- Автосохранение каждые 45 сек

## Сборка
```bash
make clean && make
```
Нужен PSPSDK (pspdev).

## Установка
```
ms0:/PSP/GAME/DALREYS/EBOOT.PBP
ms0:/PSP/GAME/DALREYS/assets/menu.bmp   (опционально)
```

## Управление
| Кнопка | Действие |
|--------|----------|
| Стик | Руль / осмотр в гараже |
| X | Газ / подтвердить |
| □ | Тормоз |
| O | Действие / телефон / компьютер |
| △ | Вид |
| L/R | Выглянуть |
| ↑ | Радио (на ходу) / выбор в меню |
| ↓ | Карта |
| START | Пауза |
